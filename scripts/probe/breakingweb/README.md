# BreakingWeb defect probes

> **Summary:** The scripts behind the BreakingWeb feasibility record: they write accessibility defects into the source of BreakingWeb's React apps, rebuild them, and measure how the agent's observation and the rendered page change. `codemod.py` was revised on 2026-10-30 (look-keeping CSS; the 2026-10-29 version is in git, commit `8b66c92`); the other 2026-10-29 scripts are the copies as run.

Records of what they showed: [`../../../docs/feasibility/2026-10-29-breakingweb.md`](../../../docs/feasibility/2026-10-29-breakingweb.md) and, for the variant gate, [`../../../docs/feasibility/2026-10-30-variant-gate.md`](../../../docs/feasibility/2026-10-30-variant-gate.md), and, for the on-path dose, [`../../../docs/feasibility/2026-10-30-on-path-dose.md`](../../../docs/feasibility/2026-10-30-on-path-dose.md), and, for function equivalence, [`../../../docs/feasibility/2026-10-30-function-equivalence.md`](../../../docs/feasibility/2026-10-30-function-equivalence.md), and, for task feasibility by replay, [`../../../docs/feasibility/2026-10-30-replay-feasibility.md`](../../../docs/feasibility/2026-10-30-replay-feasibility.md), and, for the browser-use observation, [`../../../docs/feasibility/2026-10-30-browseruse-footprint.md`](../../../docs/feasibility/2026-10-30-browseruse-footprint.md), and, for the pipeline smoke test, [`../../../docs/feasibility/2026-10-30-pipeline-smoke.md`](../../../docs/feasibility/2026-10-30-pipeline-smoke.md).

## Scripts

| File | What it does | Run as |
|---|---|---|
| `inventory.py` | Opens the start page of the first N tasks of every BreakingWeb environment (clean build), flattens the BrowserGym AXTree the way BreakingWeb's text agent does, and counts landmarks, headings, tables, named and unnamed controls, images and ARIA states. One JSON line per page. | `inventory.py OUT.jsonl N_PER_ENV` |
| `codemod.py` | Rewrites the JSX in `src/**/*.tsx` of one environment for one defect kind (`landmarks`, `headings`, `names`, `labels`, `alt`, `tableheads`, or `none` for a rebuild-only noise run), keeps class names and event handlers, and keeps the look for tag-replacing kinds: type selectors match the replacement with the same specificity, selectors of the replacement tag stop matching it, and the replaced tag's Chromium UA defaults are added in the lowest-priority cascade layer `amt-ua`. Prints change counts and risk counts. Writes in place. | `codemod.py ENV_SRC_DIR KIND` |
| `ua_delta.py` | Checks `codemod.py`'s look-keeping CSS in Chromium: on a fixture page with headings, landmarks and tables under four kinds of author CSS, compares every computed property and box of every element between real and replaced tags; also runs the 2026-10-29 CSS as a positive control. | `ua_delta.py [OUT.json]` with the BreakingWeb venv python |
| `variant_gate.py` | The variant QA gate: builds an environment clean 3 times (noise floor) and once per kind, captures every page (observation, full observation, DOM dump, full-page screenshot) and judges each variant against clean on build, console errors, page size, pixels against the clean-vs-clean floor, element boxes, DOM changes and an allowed-diff rule per kind on the observation; writes `<OUT>/<env>/gate.json` with PASS/FAIL per cell and the reason, plus a specificity control. Docstring states the checks. | `variant_gate.py capture ENV OUT`, `variant_gate.py evaluate ENV OUT`, `variant_gate.py summary OUT`; `BW_ROOT` = checkout to build in, `BW_PORT` = backend port |
| `click_effect.py` | Function equivalence: on every gate page, enumerates the clickable elements of the clean build (AX role, React click handler, non-inherited `cursor:pointer`, `<label>`), then clicks each, presses Enter and Space on buttons and records the Tab order, each in a fresh backend session and browser context, on two clean builds, the `none` sham and every kind; compares effect signatures (URL, requests, mutations, dialogs, focus, element count, console, screenshot after the action) against the clean-vs-clean floor; `recheck` retests flagged trials 3 times on fresh builds; `pc_break` is a known-answer control. Docstring states the rules. | `click_effect.py drive ENV OUT`, `evaluate ENV OUT`, `recheck ENV OUT --kind K`, `summary OUT`; `BW_ROOT`, `BW_PORT` as for `variant_gate.py` |
| `click_treated.py` | Counts the `click_effect.py` targets a kind changed (the element itself, a descendant, an ancestor) from the gate's DOM dumps and the live clean page. | `click_treated.py FX_OUT GATE_OUT ENV`, `BW_ROOT`, `BW_PORT` set |
| `replay.py` | Task feasibility by replay (the cell gate), no LLM: `compile` maps each action of a successful recorded clean run to mouse and keyboard input on the clean build (element resolved by recorded role+name with the recorded coordinates as tie-break and fallback, wheel-scrolled into view, clicked at a point whose hit test is the element; text filled and options set on the focused control); `play` replays only those input ops in a fresh session and scores the end state with BreakingWeb's evaluator; `drive` builds clean, compiles, plays clean 3 times (reference set = 3/3), then builds each kind and the `none` sham and plays the reference set (failures re-played twice); `--null` adds the do-nothing control and kind `pc_break` the known-answer break of `click_effect.py`; `summary` writes the task x kind matrix. Docstring states the rules. | `replay.py drive ENV OUT [--kinds k1,...] [--workers 2] [--null] [--controls-only]`, `replay.py summary OUT`; `BW_ROOT`, `BW_PORT` as for `variant_gate.py` |
| `replay_report.py` | Small JSON for the replay record from `replay.py` outputs: reference set and exclusion classes per env, matrix, per-cell counts, on-path flags of the reference tasks (from the on-path dose JSON), controls, raw-coordinate agreement, bundle hashes against the function-equivalence builds. | `python3 replay_report.py OUT DOSE_JSON FX_DIR > JSON` |
| `variant_run.py` | For one environment and one kind: restores the sources from git, builds and captures the clean version (observation text, full observation text and a full-page screenshot per page), applies `codemod.py` to the environment and the shared sources, builds and captures again, restores and rebuilds, and writes `<OUT>/<env>/<kind>.report.json` with changed observation lines and the share of changed pixels per page. | `variant_run.py ENV KIND N_TASKS OUT_DIR`, from the BreakingWeb root with `PYTHONPATH=.` |
| `path_replay.py` | Replays recorded browser-use clean trajectories on a clean BreakingWeb build and records, before every step, the instances each defect kind would change (DOM and AX tree, document and viewport) and, for each acted-on element, its attributes, its AX name clean / without aria-label / without aria-label and `label[for]`, and how many visible peers share that name; ends with the backend evaluator. Run it on a private copy (`/tmp/amt-syn/bw-clean`), not the shared checkout. `AMT_REPLAY_LOOSE=1` for variant builds. | `path_replay.py TRAJ_ROOT OUT_DIR [--only-success] [--tasks F] [--port P] [--workers N] [--viewport WxH]` with `PYTHONPATH` = the copy |
| `on_path_dose.py` | Per task x kind on-path exposure from the replays (static and route fallbacks), clean-run counts and headroom for all published models, cross-model agreement, browser-use selector use, candidate on-path/off-path pools. Record: `docs/feasibility/2026-10-30-on-path-dose.md`. | `python3 on_path_dose.py` |
| `variant_check.py` | Compares the replay's predicted post-defect names and counts with replays on real codemod variant builds. | `python3 variant_check.py` |
| `browseruse_capture.py` | Captures the `<browser_state>` text the stock browser-use agent (0.13.14, stock harness Browser settings, Agent defaults) sends its LLM, plus the viewport screenshot, on the same pages as `variant_run.py`, for clean builds and codemod variants; no LLM call. `diff` classifies every changed line (attribute removed, tag changed, line added) and whether a removed aria-label or alt is still printed elsewhere on the element; `validate` checks captured start pages against the recorded step-1 actions of published clean runs. Docstring states the rules. | `browseruse_capture.py drive ENV OUT --kinds k1,...`, `diff ENV OUT`, `validate ENV OUT --tasks N`, `summary OUT ENV...`; `BW_ROOT` (private copy), `BW_PORT` |
| `pilot_plan.py` | v2 pilot plan, no LLM: `select` freezes the pilot task sample and the sealed tasks by the rule in its docstring (replay reference set, not hardened, panel tier A, no unstable cell; all tableheads on-path tasks, then a seeded stratified fill to 64); `cells` lists every harness x model x task x cell with its repeats; `cost` estimates steps, tokens and dollars from recorded actions, step caps and gate observation sizes; `files` writes `cells_by_task.json` and the generated sections of `design.yaml`. Protocol: `studies/v2-pilot/`. | `python3 pilot_plan.py all [OUT]` with the BreakingWeb venv python |
| `pilot_precision.py` | Planning simulation, no LLM: null half-widths and implied run disagreement by variance setting (`precision.json`), power of every registered pilot test (`power.json`), and the main study's smallest detectable drop at the sealed task caps (`mde_sealed.json`); truth is the mean probability-scale drop over admitted tasks. | `analysis/.venv/bin/python pilot_precision.py [OUT]` (numpy, scipy) |
| `pipeline_smoke.py` | Engineering smoke test of the pilot's H1 pipeline, not data: one episode per call of BreakingWeb's `LLMAgent` (provider `bedrock`) through `agent_eval.run_episode` on a clean build or one codemod kind in a private checkout, with a logging proxy on the Converse client (fields sent, usage, stopReason, block types), the replay's Date shim and remote-request abort, a served-asset vs disk check, the forced evaluation kept, a credential check (no bearer token) and restore afterwards; `served` does the build and served check without an LLM. Record: `docs/feasibility/2026-10-30-pipeline-smoke.md`. | `pipeline_smoke.py run TASK ARM OUT [--max-steps 15]`, `served TASK ARM OUT`; cwd = `BW_ROOT` (private copy, also on `PYTHONPATH`), `BW_PORT`, `AWS_PROFILE`, `AWS_BEDROCK_REGION` |
| `h1_wrapper.py` | The pilot's H1 harness wrapper: one episode of BreakingWeb's own BrowserGym text agent on a private checkout, with no temperature on any call, explicit reasoning fields per model (Claude: adaptive thinking, `display: "summarized"`, `output_config.effort`; GPT-5.6: `reasoning.effort` and `reasoning.summary`), every reasoning block stored, the forced backend evaluation kept for every run, Date shim and remote-request abort with a self-check, a refusal to start unless the on-disk bundle equals a variant manifest, the per-task step cap from `h1_budget.py`, and per-step records (URL, exact observation text, prompt hash, reasoning, action, error, tokens, latency, stop reason). Writes an immutable `trace.json` and `manifest.json` per run. `packet` writes the blinded observer packet of `studies/v2-pilot/TRACE-CODING.md`; `probe` checks the request shape with one small call per model. Record: `docs/feasibility/2026-11-02-h1-wrapper.md`. | `h1_wrapper.py manifest --env E --build B --out VM.json`; `h1_wrapper.py run --task T --cell C --model M --manifest VM.json [--expect-bundle H] [--repeat N] [--port P]`; `packet TRACE_DIR OUT.json [--with-outcome] [--key-file K]`; `probe [--models ...] [--variants]`; BreakingWeb venv python, `BW_ROOT` = private copy (also on `PYTHONPATH`), `AWS_PROFILE=codex-DO-NOT-DELETE` for real models |
| `h1_budget.py` | Per-task H1 step cap from the recorded trajectories, no LLM: the shortest known route (Gemini reference actions, plus one scroll per replay wheel op, plus the final message), the 95th percentile of how much longer the successful published runs of the six panel models went, and an orientation allowance; reports for each rule the share of successful published runs that would have hit the cap. | `python3 h1_budget.py [OUT] [--k K] [--a A]` with the BreakingWeb venv python (PyYAML) |
| `h1_selftest.py` | Offline test of `h1_wrapper.py` with a scripted fake Bedrock client: a reference task solved end to end on the clean build, a failed run with the summary call forced, refusals on a changed bundle, a wrong expected hash, a disallowed model and an unbuilt cell, and the blinded packet. 34 checks. | `BW_ROOT=<copy> PYTHONPATH=<copy> python h1_selftest.py OUT` |
| `batch.sh` | Runs `variant_run.py` for every environment (gmail, reddit, robinhood, booking, lms, patient_portal, amazon) and every kind with 2 tasks, skipping pairs whose report exists. | `bash batch.sh` |
| `ablate.py` | Prototype of observation-layer ablation: edits a copy of the AXTree object (landmarks, headings or tables to generic; control or image names emptied), prints the changed lines, then clicks a link whose name was removed to show it still works on the unchanged page. | `ablate.py TASK_ID` |
| `show.py` | Prints the observation size of one task's start page and the lines around a given string, or says the string is not in the observation. | `show.py TASK_ID STRING` |

## What they expect

- The BreakingWeb checkout at `~/.workspace/_refsrc/BreakingWeb`, installed as the feasibility record describes (uv venv with `--extra browser-use`, pnpm 10.15.0, Node 24 at `~/.local/share/mise/installs/node/24.20.0/bin`).
- Their own location at `/tmp/amt-syn/bw-probe/`: `variant_run.py` calls `/tmp/amt-syn/bw-probe/codemod.py`, and `batch.sh` calls `/tmp/amt-syn/bw-probe/variant_run.py`. To run these copies, put them back at that path or change the two paths.
- Output in `/tmp/amt-syn/bw-variants/` (the `OUT_DIR` that `batch.sh` passes). The outputs are not kept in this repository; they are regenerated by running `batch.sh` again.

`codemod.py`, `variant_run.py`, `variant_gate.py`, `click_effect.py` and `replay.py drive` change BreakingWeb source files and rebuild `breakingweb/static/envs/`, which the backend serves; do not run them on a checkout another process is serving from (`variant_gate.py`, `click_effect.py` and `replay.py` take `BW_ROOT` for a private copy). `variant_run.py`, `variant_gate.py`, `click_effect.py` and `replay.py` restore the sources with `git checkout` afterwards, also when a build fails; check `git status` in the BreakingWeb checkout after an interrupted run.
